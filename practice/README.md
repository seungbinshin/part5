# 내 Part 4 프로젝트를 이어서 쓰기

핵심 실습은 자신의 프로젝트를 대상으로 합니다. [복사 프롬프트 3개](project-prompts.md)를 같은 AI 코딩 도구 대화에 순서대로 보내세요. 처음에 원본 프로젝트와 내려받은 강의 자료의 경로를 지정하면 도구가 구조를 확인하고 격리 사본에서 작업합니다. 필요한 권한·경로 확인과 최종 연구 판단은 본인이 합니다.

**내 구조 확인 → 근거·계획·초안 연결 → 검토·검사·인계**로 진행합니다. 기존 Skill과 자료를 재사용하고 파일 이름·식별자·스키마는 자기 프로젝트에 맞춥니다. 질문이나 근거가 없으면 필요한 입력을 확인하고 멈춥니다. 합성 예제로 자동 대체하거나 강의 예제의 정답을 자기 결과로 사용하지 않습니다.

전후 산출물과 완료 기준은 [PROJECT_GUIDE.md](PROJECT_GUIDE.md)에 있습니다. 정상 산출물뿐 아니라 근거 연결을 뺀 경우와 저장된 해시가 낡은 경우도 검사해 실패가 잡히는지 확인합니다. 원본과 기존 파일을 보존하고 현재 결과를 가리키는 인계를 남깁니다.

아래는 작은 고정 자료로 먼저 익히고 싶을 때 선택하는 합성 연습입니다. 자기 프로젝트의 완료 검사와 별개입니다. [선택 합성 프롬프트](optional-agent-prompt.md)는 사본의 `llm_wiki/research/part5-lab/`에 예제를 추가하고 제공된 검수기로 확인합니다.

## 선택 합성 예제의 전후 산출물

| 단계 | 전 | 후 | 최소 확인 |
|---|---|---|---|
| 준비 | 완료한 Part 4 원본 | 격리 사본, 추가 계획, manifest | 원본·사본의 기존 파일 보존, `ADDED`, 추가 파일 14개 |
| 검토 | 주장 C1~C3, 근거 E1~E2, 원본 CSV·메모 | `outputs/review.json` | 조건 한정·지나친 일반화·미측정 항목을 원본과 연결 |
| 검사·인계 | 자신이 작성한 보고서 | `outputs/handoff.json`, 실제 검사 출력 | 현재 보고서 해시 일치, 미해결 C2·C3, 승인 대기 |

모든 초안·근거·숫자는 교육용 합성 자료입니다. 예상 결과와 실제 학습자 출력은 구분합니다. 약 10~15분은 편성용 예상이며 실측이 아닙니다. AI 호출은 기존 도구의 사용량을 소모할 수 있고 비용·지연은 미측정입니다. 파일·명령 실행과 Python 3.8 이상이 가능한 기존 환경을 사용합니다. 새 설치가 필요하면 중단하거나 아래 수동 읽기 경로로 진행합니다.

## 합성 예제에서 확인할 것

`manuscript.txt`의 주장을 `case-data.json`만 보고 판단하지 말고 대장이 가리키는 `source-results.csv`, `source-notes.txt`까지 대조합니다. 역할의 경계는 [role-contracts.md](role-contracts.md), 인계 형식은 [HANDOFF.md](HANDOFF.md)에 있습니다.

| 판정 | 뜻 |
|---|---|
| `supported_within_scope` | 자료가 설명한 조건 안에서 지지됨 |
| `unsupported_generalization` | 주장이 자료의 조건보다 넓음 |
| `insufficient_evidence` | 판단에 필요한 자료가 없음 |

자신의 보고서를 쓴 뒤 검사합니다. 아래 명령은 **사본의 part5-lab 안에서 도구가 실행할 명령**이며 직접 입력할 필요는 없습니다.

```sh
python3 check_review.py outputs/review.json --json
python3 check_review.py outputs/review.json --handoff outputs/handoff.json --json
```

두 번째 검사는 `status: PASS`, `errors: []`와 종료 코드 0이어야 합니다. 검사기는 세 주장의 교육용 분류·근거 ID·필수 항목·입력 해시와 인계의 보고서 해시·미해결 항목·승인 대기를 확인합니다. 실제 파일 쓰기를 막는 보안 장치는 아니며 이유의 의미를 평가하지 않습니다. 원본 조건을 설명했는지 사람이 읽어 확인합니다.

`expected-review.json`은 미리 작성한 해설입니다. 학습자가 작성한 결과 대신 이 파일을 검사해 완료로 보고하지 않습니다. 본인 답을 작성한 뒤 해설과 비교할 수 있습니다.

## 합성 예제에서 막히면

| 상황 | 다음 행동 |
|---|---|
| 경로·선수 문서 불명확 | 실제 경로를 확인하고 부족한 파일을 보고합니다. 추정 경로·빈 Skill로 통과시키지 않습니다. |
| 사본·보고서가 이미 존재 | 덮어쓰지 않고 기존 작업을 확인합니다. |
| Python·도구 권한 없음 | 미실행으로 적고 중단합니다. 새 인증·설치로 임의 확대하지 않습니다. |
| JSON 형식·근거 ID·판정 오류 | 오류와 원본을 대조해 보고서만 수정합니다. 입력이나 검사기를 바꾸지 않습니다. |
| 인계 해시·미해결 항목 불일치 | 현재 보고서에서 다시 계산·정리합니다. 오래된 인계로 완료하지 않습니다. |
| 입력 파일이 바뀜 | 원본 배포본과 대조합니다. 본인 산출물은 보존하고 무조건 재실행하지 않습니다. |

## 합성 예제를 마칠 때

C2의 범위를 좁힐지, C3의 측정을 별도로 할지 판단합니다. 검사 통과는 연구자의 승인이 아닙니다. 이 실습의 완료 상태는 `awaiting-human`이며 운영 Wiki의 허브·index·log·JSON 저장소에 자동 반영하지 않습니다.

정리는 [네 번째 선택 프롬프트](optional-agent-prompt.md#선택--추가-파일만-정리)를 사용합니다. 추가 manifest에 기록된 바뀌지 않은 파일만 복구하고 학습자가 만든 `outputs/`는 남깁니다. 자세한 절차와 중단 조건은 [UPGRADE.md](UPGRADE.md)에 있습니다.

## 합성 예제를 도구 없이 읽어보는 경로

파일을 읽고 `review-template.json`의 사본에 판정·이유·다음 확인 항목을 작성한 뒤 해설과 직접 비교할 수 있습니다. 이 경우 자동 검사와 AI 호출을 수행했다고 기록하지 않습니다. Python 없이 폴더에 추가하려면 [수동 복사 안내](UPGRADE.md#python-없이-추가하기)를 사용합니다.
