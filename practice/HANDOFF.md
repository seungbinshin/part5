# 선택 합성 연습 · 현재 보고서에 연결하는 인계

이 문서는 형식 안내입니다. 학습자 인계는 `outputs/handoff.json`에 새로 작성하고 이 안내는 수정하지 않습니다. AI 코딩 도구가 [세 번째 프롬프트](optional-agent-prompt.md#3-자기-결과-검사와-인계)로 작성·검사합니다.

| 필드 | 적을 내용 | 검사 기준 |
|---|---|---|
| `input_version` | `synthetic-v1` | 검토 보고서의 입력 버전과 일치 |
| `review_file` | `outputs/review.json` | 현재 학습자 보고서 경로 |
| `review_sha256` | 보고서의 실제 바이트 SHA-256 | 저장 후 바뀌거나 다른 보고서를 참조하면 실패 |
| `pending_claim_ids` | 일반화 과다·근거 부족 판정의 주장 ID | 이번 예제에서는 C2·C3, 누락·중복 불가 |
| `approval_status` | `awaiting-human` | 검사 통과를 사람 승인으로 바꾸지 않음 |
| `next_actor` | `human` | 최종 판단은 연구자에게 남김 |

`handoff-template.json`의 빈 해시와 빈 목록은 채워야 합니다. 검사가 통과해도 이유의 타당성과 실제 원고 보존 여부는 사람이 확인합니다. 입력은 합성이고 실제 연구 데이터·반복 실험·장비 검증은 수행하지 않습니다.

준비 단계의 추가 파일·해시는 `.part5-added-files.json`, 검토 지적과 남은 확인은 `outputs/review.json`, 그 보고서를 넘기는 식별 정보는 `outputs/handoff.json`에 나눠 남습니다. 결과를 요약할 때 실제 명령·종료 코드·검사 상태도 함께 보고합니다.

C2를 현재 자료의 조건으로 좁힐지, C3의 별도 측정을 진행할지는 연구자가 결정합니다. 이 단계에서 기존 Wiki의 공용 파일, 논문 원고 또는 운영 저장소를 자동 수정하지 않습니다. 필요하다면 범위와 담당을 정한 다음 별도 작업으로 진행합니다.
