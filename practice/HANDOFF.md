# Part 5 추가 작업 인계

기록 상태: **학습자가 작성할 양식**. 아직 보고서가 만들어졌거나 사람이 승인했다고 뜻하지 않습니다.

## 보존한 기준과 실제 추가

- 작업한 Wiki 복사본: `[실제 경로를 적기]`
- 기존 Skill/절차 경로: `[plan의 skills_dir 값]`
- 추가 전 확인한 운영 규칙·Skill·템플릿: `.part5-added-files.json`의 `baseline_sha256` 참조
- 실제 추가 파일·해시: 같은 파일의 `added_sha256` 참조
- 기존 논문·연구 질문·실험 기록·AGENTS·Skill·허브·index·log·JSON 저장소 수정: **이 업그레이드에서는 없음**

자동 추가를 사용하지 않았다면 별도 복사 목록을 이곳에 적습니다. 이 양식을 편집하면 자동 복구는 변경된 추가 파일을 발견해 중단합니다. 인계 기록을 별도로 보관하고 어떤 파일을 남길지 확인한 뒤 정리합니다.

## 이번 역할 실행

입력 버전은 `synthetic-v1`입니다. 리뷰 대상은 C1~C3, 근거는 E1~E2이며 모두 교육용 합성 자료입니다. 기존 연구의 실제 측정 결과나 사실 검증으로 승격하지 않습니다.

| 항목 | 학습자 기록 |
|---|---|
| 수행자 | 사람 / 사용한 모델·도구를 실제대로 적기 |
| 읽은 범위 | manuscript → case-data 근거 대장 → source-results/source-notes 확인 여부 |
| 필수 산출물 | `outputs/review.json` 생성 여부와 검사 결과 |
| 수동 검토 | 각 reason이 조건·부정·미확인 상태를 보존하는지 |
| 미완료 사항 | 없는 근거, 판단을 보류한 항목 |
| 원고·입력 보존 | 체크섬 결과 및 원고를 수정하지 않았는지 |

## 제안과 사람의 결정을 분리

| 리뷰의 제안 | 연구자가 결정할 것 | 현재 상태 |
|---|---|---|
| C1의 제한된 범위 보존 | 표현과 근거 범위를 그대로 둘지 | 미결정 |
| C2의 일반화 범위 검토 | 범위를 줄일지, 추가 근거를 확인할지 | 미결정 |
| C3의 미측정 항목 보류 | 별도 측정을 승인할지 | 미결정 |

이 양식의 제안은 미리 준비한 교육용 해설입니다. 실제 연구자의 승인으로 바꾸려면 본인이 결정한 내용과 이유를 적습니다. 리뷰어가 자기 결과를 승인하지 않습니다.

실제 프로젝트 반영은 이번 학습 출력과 별도입니다. 승인 후 Main 한 명이 기존 Wiki의 갱신 계약을 따라 처리하며, `llm_wiki/index`, `log`, 프로젝트 공용 파일과 JSON 저장소에 여러 에이전트가 동시에 쓰지 않습니다.
