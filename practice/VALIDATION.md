# 로컬 확인 기록

확인일: 2026-10-26. Python 표준 라이브러리로 실행했습니다. 원본 연구위키를 변경하거나 원격 저장소에 쓰지 않았습니다.

## 실습 검수기

```sh
python3 practice/check_review.py practice/expected-review.json
python3 practice/smoke_test.py
```

사전 해설 검수 PASS. 정답 통과, 잘못된 일반화, 범위 밖 쓰기 선언, 거짓 승인 상태, 입력 변경, 검토 항목 누락을 검사하는 6개 테스트가 통과했습니다. 사전 해설은 작성한 교육용 자료이며 실제 모델 응답이 아닙니다.

## 기존 Wiki 추가·복구

검사에는 `nufrancis/hyresearchagent` commit `0457f15c374544337e1b2977836e428d9d687ca6`의 실제 `실습파일/LLM_Wiki_템플릿`과 두 Skill 문서를 복사했습니다. 임시 복사본에서만 `.agents/skills` 배치를 구성했습니다. 실제 기존 Wiki의 경우에는 필요한 규칙·템플릿·`skills/` 문서만 별도 임시 디렉터리로 읽어 복사해 시험했습니다. 실제 Wiki에 Skill을 등록하거나 실습 폴더를 추가하지 않았습니다.

재현 명령의 경로는 보유한 읽기 전용 자료 위치로 바꿉니다.

```sh
python3 practice/test_upgrade.py --part4-reference /path/to/part4 --actual-wiki-root /path/to/existing-wiki
```

16개 테스트가 통과했습니다.

1. dry-run은 무변경, 추가 후 사전 해설 PASS, 복구 후 기존 파일 바이트 일치
2. 기존 `part5-lab` 경로 충돌 거부
3. 선행 Skill 누락 시 정확한 경로와 함께 중단
4. 계획 후 기존 기준 파일이 바뀌면 적용 거부
5. 계획 또는 복사본 확인 없는 적용 거부
6. 추가 파일을 학습자가 편집하면 전체 복구 거부
7. manifest에 없는 사용자 보고서 보존
8. manifest 조작으로 기존 파일을 지정하면 복구 거부
9. 심볼릭 링크 대상 거부
10. 실제 Wiki의 `skills/` 경로를 명시하면 적용 가능하며 `.agents`·`.claude`를 새로 만들지 않음
11. 상위 디렉터리가 심볼릭 링크인 프로젝트 경로 거부
12. `apply --dry-run` 조합 거부와 파일 무변경
13. 첫 파일의 부분 쓰기 오류 후 잔여 폴더 없음, 같은 계획으로 재시도 가능
14. manifest의 부분 쓰기 오류 후 잔여 폴더 없음, 같은 계획으로 재시도 가능
15. 완성본 게시 오류 후 이번 호출이 만든 빈 목적지만 정리
16. 준비 중 다른 작업이 먼저 만든 충돌 파일 보존

추가 파일과 manifest는 목적지 옆의 임시 폴더에서 모두 쓰고 해시를 확인합니다. 완성 후 배타적으로 확보한 빈 목적지로 디렉터리를 한 번에 옮깁니다. 쓰기 오류가 난 임시 자료는 정리하며, 기존 파일이나 다른 작업이 만든 충돌 경로를 덮어쓰지 않습니다. 한 복사본에서는 추가·복구 작업을 동시에 실행하지 않습니다.

이 검사는 지정된 추가·복구 절차의 소프트웨어 동작을 확인합니다. 기존 Wiki의 연구 내용, Skill 등록·자동 실행 여부, 다른 에이전트의 권한 격리를 보증하지 않습니다. 테스트 임시 디렉터리는 종료 시 정리했습니다.
