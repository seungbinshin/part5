# 내 프로젝트에서 확인할 완료 기준

핵심 실습은 **학습자의 기존 Part 4 프로젝트**를 이어가는 작업입니다. [프롬프트 3개](project-prompts.md)로 구조 확인, 산출물 작성, 검토·인계를 진행합니다. 사용자 AI DRAM Wiki의 적용 사례는 참고이며 그 폴더·ID·스키마를 그대로 복사할 필요는 없습니다.

## 시작할 때 필요한 것

자신의 질문 하나, 그 질문과 관련된 읽기 허용 자료, 기존 운영 규칙·Skill 또는 절차 문서가 있어야 합니다. 입력이 없거나 무엇을 읽어도 되는지 모호하면 도구가 필요한 항목을 묻고 멈춥니다. 없는 근거를 만들거나 합성 자료로 대체해 완료하지 않습니다.

파일·명령 실행이 가능한 기존 AI 코딩 도구를 사용합니다. 처음 두 경로를 지정하고 프롬프트를 세 번 보내되 필요한 도구 권한과 경로 확인은 직접 처리합니다. 마지막에는 근거와 이유를 읽고 계획 채택 여부를 결정합니다. 호출 시간·비용·추가 확인 횟수는 환경에 따라 다르며 미측정입니다.

## 전후에 무엇이 달라지나요?

| 단계 | 기존 상태 | 기대 산출물 | 최소 확인 |
|---|---|---|---|
| 준비 | 프로젝트마다 다른 경로와 운영 규칙 | 격리 사본·실제 경로 매핑·작업 기록 | 원본 보존, 기존 Skill 재사용, 새 경로와 복구 범위 확인 |
| 연결 | 질문·문헌·기록·초안이 따로 있음 | 근거표·미실행 비교 계획·짧은 초안·역할 계약 | 질문 하나, 주장 최대 세 개, 원문 위치·조건·버전/해시 연결 |
| 검토 | 맞는지 확인하지 않은 새 산출물 | 주장별 검토·인계·실제 검사 출력 | 현재 자료 연결, 미해결 항목·다음 담당·승인 대기 유지 |

근거표에는 실제 프로젝트의 식별자를 사용합니다. 문서라면 파일과 절·줄·페이지 등 확인 가능한 위치를, 데이터라면 파일과 레코드·열·조건을 남깁니다. 해시는 실제 저장된 바이트로 계산합니다. URL만 있고 본문을 확인하지 않았다면 그 범위를 미확인으로 표시합니다.

비교 계획은 아직 실행하지 않은 제안입니다. 바꿀 변수 하나, 기준선, 평가 지표, 필요한 입력, 모르는 조건을 적습니다. 새 초안의 근거가 부족하면 그 문장을 보류합니다. 성능 향상이나 실제 실험 완료로 바꾸지 않습니다.

## 자동으로 확인할 것과 사람이 볼 것

기존 검사기가 있으면 재사용합니다. 부족할 때만 계획에 정한 새 경로에 작은 검사를 추가합니다. 특정 Wiki의 내부 스키마나 고정 정답을 강요하지 않고 현재 산출물의 연결과 상태를 확인합니다.

- 정상 산출물에서 주장-근거 연결, 원본 위치·해시, 주장별 검토 누락, 미해결 항목, 승인 대기 상태를 검사합니다.
- 별도 임시 복제 입력 두 개에서 **근거 연결 누락**, **오래된 해시**를 각각 만들었을 때 실패해야 합니다. 원본과 정상 산출물의 해시는 유지되어야 합니다.
- 검사 명령·종료 코드·출력을 남깁니다. 실행하지 못한 검사는 미실행입니다. 검사 통과를 사람의 승인으로 바꾸지 않습니다.
- 사람이 원문과 이유를 읽고 인용·조건·논리의 타당성을 확인합니다. 같은 컨텍스트로 다시 읽었다면 독립 검토라고 부르지 않습니다.

이 최소 검사는 연구의 진실성, 도구의 권한 격리, 모델 품질이나 하드웨어 성능을 보증하지 않습니다. 실제 효과를 평가하려면 승인된 별도 실험과 비교 조건이 필요합니다.

## 이어 하기와 복구

작업 기록의 원본 경로·입력 해시·소유 파일 목록이 일치할 때 같은 사본과 산출물을 재사용합니다. 입력이 달라졌거나 기존 경로와 충돌하면 변경 범위를 확인하고 멈춥니다. 매번 번호를 붙인 새 사본이나 비슷한 기능의 검사기를 만들지 않습니다.

정리는 선택입니다. 먼저 dry-run 목록을 보고 확인한 뒤 소유가 분명하고 바뀌지 않은 임시 추가만 정리합니다. 학습자가 만든 근거표·계획·초안·검토·인계와 작업 기록은 보존합니다. 원본과 원격 저장소는 이 실습에서 바꾸지 않습니다.

## 고정 예제로 먼저 연습하려면

[합성 예제 프롬프트](optional-agent-prompt.md)는 주장 세 개를 검토하는 선택 연습입니다. 제공된 검사기는 해당 고정 자료만 다루며 자기 프로젝트의 완료 검사로 대신 쓰면 안 됩니다. 합성 연습의 통과와 자기 프로젝트에 Part 5 흐름을 적용한 결과를 따로 기록합니다.
