# 선택 합성 연습 · 기존 Wiki 위에 나누는 네 역할

이 문서는 역할의 입력·출력·인계 경계를 정한 추가 안내입니다. 에이전트를 설치하거나 자동 등록하지 않습니다. 기존 Wiki의 AGENTS·README와 실행 계약이 우선하며, 실제 Skill 경로는 업그레이드 계획의 `skills_dir`와 일치시킵니다.

기존 Part 4 산출물은 다시 만들지 않습니다. `paper-reading`과 `experiment-log`는 이미 검토한 절차를 재사용하고, 부족한 원문이나 실험 결과를 Part 5 예시로 대체하지 않습니다. 아래 경로의 `<프로젝트>`는 기존 연구 폴더를 뜻하며 자동 생성하지 않습니다.

| 역할 | 기존 Wiki에서 읽을 입력 | 맡는 일 | 반환·쓰기 범위 | 넘기지 않는 권한 |
|---|---|---|---|---|
| literature-reviewer | 기존 `paper-reading/SKILL.md`, 연구 질문, `llm_wiki/research/<프로젝트>/literature.md`와 지정한 원문 | 기존 문헌 읽기 절차를 따라 근거·미확인 항목을 구분 | 검토 초안과 추가 확인 목록을 Main에 반환. 이번 실습에서는 기존 문헌 파일에 쓰지 않음 | 새 인용 생성, 연구 공백 확정, 임의 문헌·허브 갱신 |
| experiment-planner | 기존 `experiment-log/SKILL.md` 절차로 정리된 실험 기록, 조건·제약, 기존 후보표 | 비교 가능한 근거로 다음 실험 후보의 조건과 우선순위를 제안 | 후보표 초안을 Main에 반환. 기존 `plans/` 반영은 별도 승인 | 측정값 생성, 실험 실행, 예산 사용, 후보 채택 |
| draft-writer | 연구자가 초안에 쓸 범위를 확인한 문헌·실험 기록·후보표 | 근거 범위 안에서 초안과 주장–근거 대응을 작성 | 별도로 승인된 새 초안 위치. 이번 핵심 실습에서는 미리 제공된 합성 초안을 읽음 | 미실행 실험을 결과로 서술, 다른 역할 보고서 수정 |
| writing-reviewer | 같은 버전의 초안, 근거 대장, 대장이 연결한 원본 | 주장 식별→근거 대조→논리·과장·누락 확인 | 검토 산출물 `part5-lab/outputs/review.json` | 원고 수정·대필, 실험 실행, 최종 채택 |

핵심 경로에서는 reviewer만 새로 연습합니다. 문헌 수집, Skill 재생성, 실험, 긴 초안 생성을 반복하지 않습니다. 입력은 모두 합성이며 실제 Wiki의 연구 사실과 섞지 않습니다.

## 인계와 한 명의 작성자

리뷰어는 입력 버전, 읽은 경로, 근거 위치, 완료·미완료 사항과 사람이 결정할 항목을 보고합니다. Main은 [HANDOFF](HANDOFF.md)의 형식에 따라 `outputs/handoff.json`에 현재 보고서의 해시와 미해결 항목을 기록하고 함께 검사합니다. 여러 역할이 같은 `index`, `log`, `literature` 또는 JSON 저장소를 동시에 고치지 않습니다.

기존 연구위키가 JSON을 원본으로 삼고 빌드로 문서를 만드는 구조라면 파일을 직접 덧붙이는 방식으로 운영 상태를 바꾸지 않습니다. 기존 프로젝트의 명령·검증 계약을 따를지 먼저 확인합니다. 이 교육용 추가 폴더는 그 상태나 공개 파일 목록을 자동 갱신하지 않습니다.

실제 Wiki에 승격하려면 연구자가 반영할 지적과 파일 범위를 승인한 뒤 Main 한 명만 기존 규칙에 따라 순서대로 반영합니다. 이것은 실습의 자동 후속 단계가 아닙니다. 여러 리뷰어의 동의나 검사기의 PASS도 사람의 승인으로 기록하지 않습니다.
