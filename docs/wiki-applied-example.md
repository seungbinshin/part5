# 실제 적용 예시 · AI DRAM Wiki의 연구 인계 검사

이 문서는 사용자의 실제 Part 5 로컬 구현에서 공개 가능한 변경과 검사 결과만 요약한다. 강의의 `practice/` 합성 예제·사전 해설과 별개다. 원문 개인 세션, 운영 로그, 비공개 연구 자료, 키와 로컬 절대경로는 포함하지 않는다.

## 적용 전후

기준선 `880ae12`의 문헌·실험 기록 기능을 유지하고, 로컬 커밋 `556594ccd03192fe5f01b34f7860a413eb208561`에 읽기 전용 `handoff-check`를 추가했다. 이 커밋은 운영 저장소에 게시하지 않았다.

- 전: 기존 `validate`는 Wiki 상태를 검사했다. 별도 연구 인계 패킷은 검사 범위 밖(`not_covered`)이었다.
- 후: 연구 질문·자료 판본과 해시·주장별 근거·지표·범위·미정 조건과 다음 행동을 한 묶음으로 검사한다. 판본 변경, 근거 누락, 메모리 할당량을 DRAM 전송량으로 바꾸는 등의 선언 오류를 위치와 함께 반환한다.
- 검토되지 않은 주장은 `needs_review`로 남긴다. 검토 기록이 있다는 사실은 연구 채택·실험 실행 승인이나 과학적 검증이 아니다. `execution_ready`는 항상 false다.

별도 AI 검토에서 새 인계 초안의 고정 KV 예산 실험을 읽다가 활성 batch가 전역 통제변수처럼 표현된 모호성을 발견했다. 고정 활성 batch 실험과 고정 예산 실험을 구분해 수정했다. 기존 Wiki의 오류나 하드웨어 실험 결과로 보고한 사례는 아니다.

15건은 실제 연구자 오류나 자연어 의미 오류 탐지율이 아니다. 기존 검사는 해당 패킷을 다루지 않았으므로 기존 오류 15건을 고쳤다고 계산하지 않는다. 양쪽 메타정보를 함께 잘못 쓰거나 자연어만 왜곡하는 문제는 원문 검토가 필요하다. 실제 연구자 작업시간·모델 품질·GPU/DRAM 효과는 측정하지 않았다. 후속 논문 조사 메모는 이 구현 결과에 합치지 않았다.
