## 서로 다른 설명과 미검증 범위

- 초안 입력: Ch01-02 05:26은 ‘승인된 후보 표’라고 설명하지만 Ch02-03 00:59–01:09에서는 승인 대기 후보를 Discussion·후속 방향의 재료로 다룬다. 둘을 실행된 결과로 합치지 않았고 개요에 차이를 표시했다.
- 비용 추정: Ch02-02 04:53–05:04는 실측·제약 근거를 우선하며 추정일 때는 추정임과 계산 근거를 쓰게 한다. ‘모든 추정을 금지한다’로 바꾸지 않았다.
- 초안 부재: Ch01-02 00:53–01:17은 강사의 시연 작업 공간에 초안이 없다는 설명이다. 모든 수강자에게 기존 초안이 없다는 뜻으로 일반화하지 않았다.
- 시연의 논문 초안은 Ch02-04 06:03–06:15에서 합성 데이터 기반이라고 밝힌다. 지적 건수를 실제 연구 오류 탐지율로 표시하지 않았다.
- 원전사에는 산출물 생성과 서로 다른 지적·의견 충돌의 시연이 있다. 역할 분리의 시간·토큰·비용 절감량, 반복 비교 실험, 연구 품질 향상이나 심사 독립성의 별도 측정은 제시되지 않는다. 여기서 말하는 기대효과는 강의의 설계 의도다.
- `.cloud`, `승인되기`, `synthesis.ind` 등은 오인식 후보이며 원음·영상 미대조 상태다. 화자 표지가 없어 강사의 설명과 읽어 준 AI 응답을 모두 확정해 분리하지 않았다. Ch03-01 06:17→06:47의 간격을 포함해 누락 설명·정확한 경로를 추측 복원하지 않았다. [전사 확인 기록](../TRANSCRIPT_NOTES.md)을 유지했다.

im-not-ai의 텍스트 규칙은 새 한국어 설명을 다듬는 데만 적용했다. 원전사·직접 인용은 수정하지 않았고 공식 정량 게이트·등급은 산출하지 않았다.
